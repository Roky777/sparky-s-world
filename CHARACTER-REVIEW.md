# Sparky character reference polish

Open /character-review/?view=back to inspect the model. Front, side, back, animation, rig and mesh controls are available. The game hub keeps its previously deployed character while this model is reviewed.

The current character is preserved with a fuller rounded back, a continuous outward face-profile curve (no separate nose), five closed 3D back flame meshes and the original brown hands. Flame roots sit inside the body. Four morph targets on each layer give staggered, looping tip motion in Idle_Blink and Fire_Ambient. The original 15 curated gesture clips remain, plus ambient fire.

The 2.78 MB GLB includes the geometry, morphs and animation. Web rendering adds authored self-lit flame shading, small rising/fading wisps and restrained bloom. The GLB alone uses its portable base materials; it does not encode the custom WebGL shader.

The editable Blender source is stored locally at characters/sparky-fireball-v2/source/sparky-back-flames-authoring.blend. Shape and animation checks are in validation/character-review. Earlier smoke, density-field and new-model generation experiments were not selected or published.
